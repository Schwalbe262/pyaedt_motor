# 모터 설계에서 확인하는 값

성능 비교는 회전수와 요구 토크를 같게 맞춘 뒤 합니다. 전류나 β를 고정한 비교는 원인 분석용이고, 같은 부하에서의 최적 운전점 비교와 구분합니다.

| 항목 | 단위 | 의미와 사용 |
|---|---|---|
| 평균 토크 | Nm | 마지막 정상상태 전기 주기의 시간 적분 평균. 요구 토크 충족 여부 |
| 토크 최소·최대·리플 | Nm, % | 리플은 `(최대−최소)/abs(평균)×100`. 평균이 0에 가까우면 절댓값도 함께 확인 |
| 코깅 토크 | Nm | 무전류 운전에서 자석·슬롯으로 발생하는 토크. 부하 토크 리플과 별도 평가 |
| 철손 | W | 지정한 철심 손실 모델의 결과. 강종·B-H·주파수·온도·계수 단위 확인 |
| 고체 손실 | W | 도체 영역의 손실. 자석·철심·권선 중 어떤 영역이 포함됐는지 확인 |
| 동손 | W | 상별 측정 전류의 RMS와 상저항으로 계산. 권선 온도·병렬수·엔드턴 가정 포함 |
| 전자기손실 기준 효율 | % | `Tω/(Tω+포함 손실)×100`. 모든 필수 손실이 유효해야 계산 |
| 전류·Id·Iq·β | A, ° | 피크와 RMS 구분. 현재 규약은 `Id=−Ipeak sin β`, `Iq=Ipeak cos β` |
| 단자전압·전압 여유 | V | 같은 운전점에서 인버터 전압 제한 확인. 상·선간 및 피크·RMS 구분 |
| 3상 전압 span | V | `max_t(max(Va,Vb,Vc)-min(Va,Vb,Vc))`. 고조파를 포함한 PWM 전압 요구량. 현재 예비 제한은 여유율 0.95와 Vdc 200 V의 곱인 190 V |
| 무부하 역기전력·THD | V, % | 무전류 파형의 기본파와 고조파. 부하 유기전압과 구분 |
| dq 자속연계 | Wb | 권선 자속연계를 검증된 회전자 좌표계로 변환. 전압·토크 관계 진단 |
| Ld·Lq | H | 운전점과 계산 방식에 의존. 현재 기본은 Maxwell의 겉보기 인덕턴스 행렬 변환 |
| 자속밀도·포화 지표 | T | 선택된 필드 해석에서 치·요크·브리지의 국부 포화 확인 |
| 전류밀도·점적률 | A/mm², 비율 | 권선이 슬롯 안에 들어가고 전류 한도를 만족하는지 확인 |
| 실제 코일 창 면적·최대 점적률 | mm², 비율 | CAD Boolean 이후 24개 코일 측 면적을 직접 읽고, 고정 도체 단면적×턴수로 해석 전에 검사. 전류를 낮춰 점적률을 줄이지 않음 |
| 실제 메시 요소 수 | 개 | 생성된 메시 통계에서 확인. 입력 `mesh_*_elements`는 각 작업의 추가 요소 한도이며 전체 요소 수나 목표 해상도를 뜻하지 않음 |
| EnergyError | solver 원래 단위 | 선택 진단 보고서의 원래 값·단위를 보존. 자기 에너지나 손실 W로 해석하지 않으며, 단위 없는 값에 임의로 %를 붙이지 않음 |
| 활성 체적·자석량 | mm³, kg 등 | 크기·재료량·효율 간 비교. 활성 체적과 케이스 포함 외형 구분 |
| 주기 변화량 | %, 원래 단위 | 마지막 두 주기의 평균 변화. 정상상태 도달 여부 진단 |
| 전력수지 잔차 | W, % | 상별 전압×전류 평균과 기계출력·포함 손실의 차이. 손실 모델의 피드백 여부도 함께 해석 |
| 단계별 실행 시간 | s | 시작·형상 생성·설정·해석·결과 추출. 같은 하드웨어 조건에서 비교 |

β=30°는 하나의 비교 조건입니다. 설계마다 자속·포화·Ld/Lq가 달라지므로 전기각 영점을 먼저 검증하고 전류와 β를 탐색합니다. 저속의 MTPA와 고속의 전압 제한 운전, 손실을 포함한 최대 효율 운전점은 서로 구분합니다.

현재 새 연구 사양의 M19 기준 강판은 실습 PNF 강판과 다른 재료입니다. 재료 지문과 권선 조건이 일치하는 영점 보정·수렴 검증을 새로 수행한 뒤 성능을 비교합니다.


CSV 전압 이름은 아래처럼 구분합니다. 현재 학습·설계의 전압 제한은 물리 단자전압과3상 span을 사용합니다.

| CSV 이름 | 뜻 |
|---|---|
| `output_back_emf_phase_last_peak_abs_v` | Ansys가 직접 보고한 유기전압의3상 최대 절댓값. 진단용이며 단자전압과 구분 |
| `output_back_emf_phasea_h1_cos_peak_v`, `output_back_emf_phasea_h1_sin_peak_v` | 자속 변화율에서 계산한 A상 기본파의 부호 있는 두 계수. 기본파 진폭은 두 계수의 제곱합 제곱근 |
| `output_phase_voltage_last_peak_abs_v` | `dλ/dt+Ri`로 계산한 실제3상 단자전압의 최대 절댓값 |
| `output_voltage_span_last_peak_v` | 같은 순간3상 최대·최소 전압 차이의 주기 최대값. 인버터190 V 제한 판정에 사용 |

현재 손실 피드백과 자석 와전류가 켜진 무전류 토크에는 손실에 의한 저항 토크도 포함됩니다. 이를 순수 코깅 토크로 해석하지 않습니다.

해석 설정 `solver_nonlinear_residual`은 기본0.005이며 유한한 양수로 지정합니다. 선택 프로파일·입력 기록·설정 지문에 포함됩니다. `solver_output_error`는 기본True이며,False면 선택적인 EnergyError 보고서만 생략하고 비활성 사유를 남깁니다. 이 설정 변경의 정확도·속도 효과는 같은 조건의 직접 해석으로 확인해야 합니다.


[공식 v252 설명](https://ansyshelp.ansys.com/public/Views/Secured/Electronics/v252/en/Subsystems/Maxwell/Content/Maxwell/DefiningSettingsontheSolverTabforTransientSolutions.htm)은 GUI의 Output error를 잔차 에너지/전체 에너지의 백분율로 정의합니다. 현재 수집한 `EnergyError []`의 숫자 내보내기 배율과 그 정의의 직접 연결은 확인되지 않았으므로,31.63823/30.82349 등의 원시값을 보존하고 임의로% 변환하거나 새로운 판정 기준에 사용하지 않습니다. `UseNonLinearIterNum`은 수동 최소·최대 반복수 범위를 지정하는 스위치이며, B–H 곡선은 재료 정의에서 검증합니다.
