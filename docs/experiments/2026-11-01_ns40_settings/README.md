# Ns40 설계 후보의 실제 모델 설정 검증

2026-11-01, Source17의 고정 코드 `98ed58a`와 동일한 private library를 사용해 Windows/Ansys 2025.2에서 두 속도를 한 건씩 실행했습니다. **두 건 모두 설정 전용이며 FEA 계산은 0회입니다.** 요청한 M19/Ns40 모델이 실제로 구성되고 저장·종료되는지를 확인했습니다.

직경 입력은 297.612064518 mm, 도체면적은 15.320646925709 mm²입니다. 실제 권선창 24개, 상별 코일 면 8개와 10턴 배정, 병렬 1개, M19 B-H 23점의 Native 읽기 검증, 깊이의 설정 전후 확인, 저장 파일의 권선·재료·과도해석 설정·보고서 9개와 빈 Solutions를 검사했습니다. 두 소유 Native 프로세스의 종료와 Python client retirement도 확인했습니다.

전류·β·저항은 기존 생성기의 `:g` 명령 형식으로 저장됩니다. 요청값과 저장 문자열을 [metrics.csv](metrics.csv)에 함께 기록했습니다. 형상 입력은 AEDT가 실제로 저장한 15자리 유효숫자 표현과 필드별로 대조했습니다. 단위·식·슬롯·극수·나머지 운전 명령은 그대로 비교했고, 변조 반례도 거부했습니다. 이전 순수 검사기의 import 경로 오류와 문자열 자릿수 오류는 보존하고 별도 검사기에서 재평가했으며 Native를 다시 실행하지 않았습니다.

**이 결과는 토크·전압·효율 검증이나 최적설계 합격을 뜻하지 않습니다.** 전기 영점 숫자는 미검증 자리표시자이고 calibration ID는 비어 있습니다. β도 최적값으로 인증하지 않았습니다. 다음 단계는 M19/Ns40의 영점·좌표 기준을 확인하고 두 속도의 직접 FEA로 전압·전류·토크 제한을 검증하는 것입니다. 기존 Ns48 회귀모델의 R²나 사용 승인은 옮기지 않습니다.

검토 가능한 입력은 [case_inputs.json](case_inputs.json), 원본 파일 위치·해시와 소유권 근거는 [provenance.json](provenance.json)에 있습니다. 이 JSON은 입력 기록이며 승인된 FEA 실행 계획이 아닙니다. 원시 AEDT·전체 로그는 C: 실행 폴더에 보존했습니다. 기록한 시간은 해당 두 설정 실행의 실제 구간이며 다른 모델의 속도 개선 비교값이 아닙니다.
