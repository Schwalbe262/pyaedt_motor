# IPMSM 전기각 기준과 설계군 좌표

## 문제와 적용한 변경

기존 영점 보정은 한 형상·재료·권선·생성 코드에 결합됩니다. 다른 형상에 같은 보정 ID를 붙이면 기존 검사가 거부합니다. 이 경로와 `calibrate_ipmsm_beta.py`는 유지합니다.

별도의 선택형 `fixed_empirical_family_reference_v1`을 추가했습니다. 실제 두 속도에서 관측한 기준 형상의 영점을 공통 계산 좌표로 선언하고, 사용한 생성 코드·재료·권선·회전 방향과 각 결과의 실제 적용 상태를 연결합니다. 이 선언은 모든 형상의 역기전력이 d축에 정렬되거나 q축 자속이 0이라는 뜻이 아닙니다. β30°도 최적각으로 지정하지 않습니다.

원점 생성 코드와 해석에 사용할 생성 코드를 각각 고정합니다. 두 코드가 다르면 좌표를 정의하는 구현과 라이브러리·재료가 같은지 검사합니다. 메시 코드의 변경만으로 수치 정확도나 역기전력 정렬이 같다고 판단하지 않습니다. 원래 보정 ID와 구분되는 `family-reference-frame:sha256:` ID를 사용합니다.

## 실제 증거와 연결

`src/pyaedt_motor/reference_frames.py`가 수집한 로컬 파일의 매핑을 읽습니다. 원격 경로 문자열만으로 결과를 승인하지 않습니다.

- 최초 파일 크기·SHA를 고정하고, 같은 파일에 다른 해시를 제시하거나 검증 중 파일이 바뀌면 거부합니다.
- 성공한 원점 두 건의 작업 상태·입력·실행 기록·실제 설정·저장 AEDT를 대조하고 원래 보정 결과를 재계산합니다.
- 실제 3상 권선의 서로 다른 양의 정수 ID, 24개 코일의 연결·극성·턴 수, 8개 자석의 재료·방향과 회전 할당을 확인합니다.
- 코어·권선·자석·축·공기 등 38개 객체의 실제/저장 재료 할당을 확인합니다.
- 학습에 전달한 출력·진단·입력 행을 수집 원본과 대조합니다. PID·개수에는 근사 비교를 사용하지 않습니다.

실패 행은 이 좌표 검증에서 성공 행으로 바꾸지 않습니다. 기존 생산 학습 CLI의 실패 상태·유한 출력·수치 품질 검사는 유지합니다. 모델과 최적화 단계에서도 같은 선언과 실제 결과 매핑을 요구합니다.

## 사용 흐름

우선 다음 명령으로 미발행 선언을 검사합니다. Native나 FEA를 실행하거나 ID를 발행하지 않습니다.

```text
python -m pyaedt_motor.reference_frames --origin-manifest origin.json --frame-evidence mapping.json --frame-evidence-root collected_root
```

검토 후 Python API `draft_reference(..., assign_identity=True)`로 별도 ID를 가진 선언을 만들 수 있습니다. 선언과 매핑은 변경하지 않고 보관합니다. 품질 비교에는 `--reference-frame-manifest`, DOE와 최적화에는 기존 `--calibration-manifest` 인자로 전달하며, 관련 CLI에 `--frame-evidence`와 `--frame-evidence-root`도 함께 지정합니다. 학습 spec의 `reference_frame`과 `beta_calibration` 역시 같은 선언을 가리켜야 합니다.

Windows 학습·최적화 실행에서는 두 증거 경로도 소스 동결 전에 절대경로로 변환합니다. 공백이 있는 경로와 `--flag=value`·분리형 인자를 함께 검증했습니다.

선택할 해석 프로파일에는 같은 설계군 좌표의 실제 품질 비교 증거가 필요합니다. 코드 구현만으로 프로파일·학습 모델·최적설계가 승인되지는 않습니다. 기존 형상별 보정 모드는 추가 인자 없이 유지됩니다.

## 확인한 개선과 남은 검증

관련 166개 검사, 독립 검토, 부모의 핵심 25개·Native CLI/소스 동결 9개 검사와 실제 Source11 결과 두 건의 각 888열 재현을 통과했습니다. 실제 원점 Source570에서 메시 제어를 보강한 Source1815까지의 좌표 구현도 대조했습니다. 다섯 물리 생성 파일과 기존 형상별 보정 검사는 변경하지 않았습니다.

현재 새 설계군 ID는 발행 전입니다. 공개 실행 경로의 병렬 자원 설정을 검증한 뒤 사용할 생성 코드 범위를 고정하고, 실제 형상·운전점의 품질 증거를 확보해야 합니다. 전체 10개 출력의 시험 R² 기준과 최종 두 속도 설계 검증도 남아 있습니다.
