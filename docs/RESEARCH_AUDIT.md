# IPMSM 연구 점검 기록

2026-10-30 개선 작업을 시작했습니다. 이 문서는 진행 중인 근거와 판단을 기록하며, 최종 성능 개선 결과는 실험이 끝난 뒤 추가합니다.

## 출발점

- 최근 v2 데이터는 1,600행이지만 독립적인 형상은 260개입니다. 운전점·반복 행 수와 형상 수를 구분해야 합니다.
- 토크 시험 R²는 0.845694, 효율은 0.603074입니다. 주요 8개 중 7개가 0.95 기준에 미달합니다. 상세 수치는 `reports/baseline_20261030.json`에 기록했습니다.
- 기록상 케이스 시간 중앙값은 약 77분입니다. 노드 점유·시작·모델링·해석·추출이 포함되므로 순수 해석 속도로 해석하지 않습니다.
- 기존 p174 모델에는 전체 360° 형상에 대한 대칭 배수 문제로 약 4배의 토크 차이가 확인된 이력이 있습니다. 해당 모델은 기준 모델로 승격하지 않습니다.
- 최신 v2는 이미 β=0~80°와 전류 변화를 포함합니다. β=30° 고정 경로와 최신 경로가 공존한다는 점을 먼저 정리합니다.

## 확인한 코드 문제와 수정

1. 다른 브랜치에 있던 `Nonemm` 메시 설정 우회, 인덕턴스 CSV 구분자 처리, 세션 유지 수정 3건을 통합했습니다.
2. 필수 설정 실패와 AEDT 검증 실패가 해석 전에 중단되도록 했습니다. 메시·권선·재료·운동 등의 적용 결과를 `setup_audit.json`으로 보존합니다.
3. 일부 손실 누락 상태에서 유효한 총손실·효율을 만드는 경로와, 마지막 주기가 없을 때 전체 파형을 대신 쓰는 경로를 제거했습니다.
4. 신규 결과에는 시간 적분 평균·RMS와 마지막 두 주기의 변화량을 기록합니다. 주기의 중복 끝점을 같은 가중치로 다시 세지 않습니다.
5. `setup-only`에 해석 출력 검사를 적용하는 오류를 실제 로컬 스모크에서 발견해 수정했습니다. 실패 행이 있으면 배치 프로세스도 실패 코드를 반환합니다.
6. 기존 원형 경계가 고정 72각형으로 생성되는 점을 확인했습니다. 정확한 원호를 사용하는 형상 경로를 추가했고 실제 설정 스모크가 통과했습니다. 해석 오차·시간 개선 여부는 짝지은 실험으로 확인합니다.

## 추가 확인이 필요한 물리 가정

- 27PNF1500 손실 계수와 30PNF1600 B-H 곡선의 조합은 동일 재료의 실측 물성으로 볼 수 없습니다. 재료별 출처와 근사 범위를 표시해야 합니다.
- 철심의 적층 모델과 벌크 와전류 설정, 자석의 와전류와 `SolidLoss` 집계 범위를 확인해야 합니다.
- 전기각 영점, 부하 유기전압과 무부하 역기전력, 겉보기·증분 인덕턴스의 정의를 각각 확인해야 합니다.
- 반복 해석의 작은 차이는 반복성 근거입니다. 메시·시간 간격에 대한 수렴이나 실제 물리 정확도의 증거를 대신하지 않습니다.

## 판단 기준

실제 4주기·90단계/주기 스모크는 전체 498.386초, 순수 해석 452.452초였으며 토크·철손·고체손실의 마지막 주기 변화량이 각각 0.0164%, 0.3237%, 0.0107%였습니다. 인덕턴스 계산을 생략한 진단이므로 정식 학습 데이터나 기존 77분 기록과 직접 비교하는 속도 개선 실적으로 사용하지 않습니다.

### 전압의 시간 차분 검증

실제 파형에서 AEDT 유기전압은 자속연계의 1차 후진 차분과 상대 RMS 오차 약 2.2e-13으로 일치했습니다. 중심 차분과는 약 4%의 파형 차이가 있었고, 단순 보고서 전압으로 계산한 입력 전력의 전력수지 잔차는 5.23%였습니다.

닫힌 정상상태 자속 주기를 주기 FFT로 미분하고 저항 전압을 더해 재계산했을 때 잔차는 0.0213%였습니다. 원본 AEDT 보고서는 유지하며, 재계산 전압·방법·주기 닫힘 오차를 별도로 보존합니다. 이 방법은 해석식으로 아는 파형과 RL 회로의 전력수지 테스트도 통과했습니다. 기준 해석과의 메시·시간 간격 비교는 별도로 수행합니다.

### 설정·테스트 환경

철심의 초기 Eddy Effect는 꺼져 있었고, 자석에는 별도의 0 A 고체 전류 경계가 있습니다. 명시적 자석 Eddy Effect 설정 전후 스모크의 고체 손실이 모두 약 7.51 W이므로 기존 자석 손실 누락을 확인한 것으로 해석하지 않습니다.

관련 테스트 150개와 소스 구문 검사가 통과했습니다. Y:에서 실행한 전체 테스트 1,516개는 실패18·오류100·건너뜀6이었으며, C: 경로만 허용하는 과거 실행 계약과 고정 소스 검증의 영향을 포함합니다. 그중 새 소스 지문이 임시 작업 경로를 참조하던 9개 오류는 수정하고 관련 테스트로 확인했습니다. 전체 검사는 C:의 고정 실행본에서도 재확인해야 합니다.

Y:에서 짧아지는 파일을 덮어쓴 뒤 이전 파일의 끝부분이 남는 현상도 확인했습니다. 코드 반영은 임시 파일에 쓴 뒤 교체하고 원문 바이트·구문을 재검증하는 도구를 추가했습니다. 과거 계약의 경로 보호 규칙은 변경하지 않았습니다.

동일 형상·운전점·계산 자원에서 비교합니다. 기준 해석 대비 토크 1%, 개별 손실 5%, 총손실 3%, 효율 0.5%p 이내를 수치 오차 기준으로 사용합니다. 더 미세한 기준 해석도 추가 세분화로 확인합니다. 기준을 만족하는 설정 중 가장 빠른 설정을 선택합니다.

현재 자료는 2D 전자기 설계 검증용입니다. 효율에는 철손·고체 손실·계산한 동손을 포함하며, 기계 손실과 인버터 손실의 포함 여부를 함께 기록합니다.

## 전체 인덕턴스·학습 입력 검증

4주기·90단계에 Ld/Lq까지 계산한 세 번째 로컬 해석은 531.629초에 완료됐고, 정상상태·결과 CSV·학습 소스 지문 검사를 통과했습니다. 전력수지 잔차는 0.02188%였습니다. 메시 수렴 완료를 뜻하지는 않습니다. 클러스터 n111의 설정 스모크도 26.621초에 통과했습니다.

## 회귀 모델과 비활성 설계 변수

기존 1,600행을 형상 그룹으로 분리하고, 학습 그룹 내부에서만 모델을 선택한 물리 정규화 실험에서 평균 토크 R²는 0.8614, 철손 0.9526, Ld 0.8542, 효율 0.7862였습니다. 자석 고체 손실은 0.7130으로 여전히 낮고, Lq도 기존 모델보다 나빠졌습니다. 전체 목표를 통과한 모델로 승격하지 않았습니다. 보고서는 `reports/physics_benchmark_1600_20261030.json`, 원본 실행 코드·모델은 C: 실행 폴더에 있습니다.

`stator_shoe_thick`는 변수로 저장되지만 현재 `module/ipmsm_geometry.py`가 참조하지 않습니다. 현재 형상의 슈 높이는 `stator_gap`, 실제 공극은 `rotator_gap`이 제어합니다. 새로운 물리 특징에서는 비활성 변수를 제외합니다. 기존 모델·결과 파일의 의미를 바꾸어 재표기하지 않습니다. 초기 비교 보고서는 이 제외 전 코드이며, 해당 코드도 실행 결과와 함께 보존했습니다.

`python -m pyaedt_motor benchmark`는 원시 특징 ExtraTrees, 물리 특징·출력 정규화 ExtraTrees/LightGBM/RBF를 비교합니다. 선택은 학습 형상의 내부 홀드아웃만 사용하고, 별도 보정 형상은 보존합니다. 시험 결과가 좋더라도 이 진단 명령만으로 최적설계에 사용할 모델을 승인하지 않습니다.

정상상태의 전류각 선정에는 전류·전압 제한과 전기각 영점이 필요하며, 일반적인 설계 비교를 위해 제어기 과도응답까지 매번 계산할 필요는 없습니다. 관련 식과 제한 곡선은 [MathWorks의 PMSM 제한 곡선 설명](https://www.mathworks.com/help/mcb/gs/pmsm-constraint-curves-and-their-application.html)을 참고했습니다. Maxwell 과도해석의 메시를 별도 검증해야 하는 이유는 [Ansys의 과도해석 메시 설명](https://innovationspace.ansys.com/knowledge/forums/topic/em-faq-how-to-link-the-mesh-from-a-static-solver-to-transient-solver-in-maxwell/)과도 일치합니다.

## 재료 적용과 B-H 곡선 추적

- **문제:** 재료 setter의 캐시가 실제 AEDT 적용 실패를 숨길 수 있었습니다. B-H 곡선의 점 개수·최대값만으로는 내부 포화 특성 변경도 구분하지 못했습니다.
- **시도:** editor에서 객체별 재료를 다시 읽고 철심·자석·권선 누락을 검사합니다. `magnet_space`는 air로 지정합니다. 전체 B-H 곡선의 해시를 재료 지문에 포함하고, 엄격한 해석은 곡선 누락·잘못된 값·비단조 곡선을 거부합니다.
- **확인:** 실제 공기 공간의 copper 지정이 수정됐습니다. 동일 입력 전후의 토크는 32.660623→32.661009 Nm(+0.00118%), 철손은 +0.0111%였습니다. 이 오류를 큰 성능 저하의 원인으로 보지는 않습니다. B-H 내부 점만 바뀌어도 지문이 달라지는 검사도 통과했습니다.
- **남은 검증:** 동일 강판의 검증된 B-H·손실 물성 확보가 필요합니다. 현재 서로 다른 강판 자료의 근사 조합이라는 한계는 남습니다.

## 고조파를 포함한 인버터 전압과 설계 A

- **문제:** 전체 파형의 상전압 peak를 정현파 기본파 한계 `Vdc/√3`와 비교하면 고조파·공통모드가 있는 파형을 잘못 판정할 수 있습니다.
- **시도:** 실제 3상 파형에서 `span=max_t(max(Va,Vb,Vc)-min(Va,Vb,Vc))`를 계산합니다. 이상적인 평균 PWM 모델에서 공통모드 중심화 후 필요한 최대 절댓값은 span/2입니다. 따라서 현재 예비 제한은 `span≤0.95×200=190 V`로 정했습니다. 판정식은 [TI의 공식 SVGEN min-max 구현](https://software-dl.ti.com/processor-industrial-sw/esd/motor_control_sdk/am261x/2025_00_00_06/docs/api_guide_am261x/svgen_8h_source.html)의 중심화에서 유도했습니다.
- **확인:** 저장된 원격 파형 51개를 보강했습니다. 재실행 시 원본 SHA 변경 0건, 파생 CSV 바이트 동일을 확인했습니다. 상전압 peak 검사를 통과해도 PWM duty가 범위를 벗어나는 고조파 반례도 검사했습니다. 이후 도착한 기준 파형은 추가 수집합니다.
- **설계 시도:** 기존 `v2s1_0070_rated_torque_02`를 직경 297.612 mm·적층 70 mm로 수정하고 저항·점적률을 다시 계산했습니다. 1200 rpm, 105 A peak, β=20°에서 59.8026 Nm·전자기 손실 기준 효율 95.0419%였습니다. 목표 59.6831 Nm 대비 여유는 약 0.20%뿐입니다. 최초 고속 6점은 span 201.88~279.91 V로 모두 190 V를 넘었고, 더 작은 음의 d축 전류 영역 12점을 추가 제출했습니다. 105 A·β=30°의 철손 비주기 실패도 그대로 보존했습니다.
- **남은 검증:** 설계 A는 아직 후보입니다. 저속·고속 모두 수렴된 해석으로 제한을 충족해야 합니다. 190 V는 설계 여유율 가정이며 dead time·소자 전압 강하·유한 스위칭 주파수의 검증은 별도입니다.

## 새 데이터·모델·실행 경로

- **문제:** 같은 형상의 운전점 혼입, 원시 형상과 유효 형상의 중복, 모델·데이터·코드 출처 불일치는 평가를 왜곡할 수 있습니다.
- **시도:** 형상 그룹별 학습/보정/시험 분리, 학습 그룹 내부 선택, 공동 오차 보정과 입력 범위 검사를 추가했습니다. 전압 span을 포함한 8개 기본 출력으로 총손실·효율까지 총 10개를 검증합니다. 보정·시험 출력은 모델 선택에 쓰지 않으며 소스·의존성·원본 데이터도 봉인합니다.
- **확인:** 기존 1,600행은 v3/span 부족으로 새 학습 전에 거부됐습니다. 새 CLI·DOE·모델·최적화·수집·파형 관련 19개 모듈의 242개 검사가 C 고정 실행본에서 통과했습니다. 기존 v4의 고정 소스·승인 계약은 완화하지 않았습니다. 실제 제출 후에는 스케줄러 full-detail 목록이 cursor를 무시하는 문제를 발견해 compact 목록+개별 조회로 바꾸고, 제출된 12건을 중복 없이 다시 인계했습니다.
- **남은 검증:** 새 연구 모델은 아직 학습·승인하지 않았습니다. 수렴된 프로파일과 새 생산자 검증 후 기본 720형상×3운전점=2,160건을 생성합니다. 구현 문서는 `DATASET_V3.md`, `PHYSICAL_MODEL.md`, `PHYSICAL_OPTIMIZATION.md`, `CLUSTER_RUNS.md`에 있습니다.

시간 단축을 위한 node-local scratch 실행·검증된 결과 복사도 구현하고 가짜 실행 및 독립 검토를 통과했습니다. 실제 Linux FEA·저장 프로젝트 재열기·GPFS 대비 속도는 아직 검증하지 않았습니다. 실제 원호 Band는 설정 검사와 경계 1개 readback을 통과했습니다. 이때 전체 389.978초 중 360.429초가 Desktop 시작, 형상 생성·설정은 약 29초였으므로 원호 변경의 계산 비용 증가로 해석하지 않습니다.
